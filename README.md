# WorkSpace — сайт управления коворкингом (КР №3)

Учебный frontend-проект: многостраничный сайт коворкинга с онлайн-бронированием
переговорок и профилем клиента. **Без бэкенда** — все данные хранятся в браузере
(localStorage).

Контрольная работа №3 по теме «Адаптивная вёрстка и доступность многостраничного
HTML/CSS-сайта».

## Страницы

| Страница | Содержание |
|---|---|
| `index.html` | Лендинг: hero-блок, преимущества, о пространстве, популярные переговорки, тарифы с фотографиями, карусель отзывов, FAQ (accordion), CTA |
| `rooms.html` | Каталог аудиторий: фильтры (вместимость, цена, оснащение), карточки, бронирование через модальное окно |
| `room.html?id=N` | Детальная страница переговорки: фото, описание, характеристики, оснащение, бронирование |
| `conferences.html` | Каталог конференц-залов на 16–180 гостей: фотографии, цены, оснащение и заявка на событие |
| `offices.html` | Офисы и бизнес-этажи для компаний на 8–45 сотрудников: фотографии, цены и условия аренды |
| `profile.html` | Профиль клиента: регистрация/вход, редактирование данных, список бронирований с отменой и избранные переговорки |

## Дополнительные возможности

- сравнение до трёх переговорок по цене, площади, вместимости и оснащению;
- автоматический расчёт аренды и дополнительных услуг при бронировании;
- избранные переговорки и последние четыре просмотренные комнаты для авторизованного пользователя;
- три учебные московские локации с встроенной Яндекс Картой на главной странице.

Избранное и история просмотров привязаны к email аккаунта и хранятся в `localStorage`.

## Подключение Bootstrap

В проекте Bootstrap подключён **локально**. Файлы фреймворка размещены в папке
`vendor/bootstrap/`. Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключается **после** Bootstrap и переопределяет
фирменный стиль (изумрудный акцент `#059669`, скругления, фокус-состояния).

## Технологии

- Семантический HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`);
- Bootstrap 5: сетка (`container`, `row`, `col-*`), `navbar`, `card`, `btn`, `badge`,
  `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `carousel`,
  `accordion`, `nav-pills`, `breadcrumb`, `toast`;
- CSS: переменные в `:root`, Flexbox/Grid, состояния `:hover`/`:focus-visible`,
  `prefers-reduced-motion`;
- JavaScript: DOM, события, валидация форм, localStorage (вместо бэкенда).

## Доступность и адаптивность

- skip-link «Перейти к содержимому» на всех страницах;
- `alt` у всех изображений, `aria-label`, `aria-live`, `aria-current`, `invalid-feedback`;
- видимый фокус (`:focus-visible`) на всех интерактивных элементах;
- адаптивная сетка: 1 колонка (мобильные) → 2 (`md`) → 3 (`lg`);
- мобильное меню navbar, поддержка `prefers-reduced-motion`.

## Учебная авторизация

Авторизация реализована только для демонстрации: аккаунты и бронирования хранятся
в `localStorage` браузера, пароль не защищён. Не используйте настоящие пароли.

## Запуск

Проект статический — достаточно открыть `index.html` в браузере или поднять
локальный сервер:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```
